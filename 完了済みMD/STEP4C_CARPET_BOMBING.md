## 2. 目的

エアストライクを「5発ばらまき」から「**編隊による1本の爆撃線**」に変える。

狙いは **1入力あたりの破壊量を大きくして、クリック疲れを減らすこと**。クールダウンを3秒→20秒に伸ばす代わりに、1回の威力を大幅に上げる。

**削除するキー**: `BombCount`(5)・`Scatter`(15)。絨毯爆撃では意味を失う。

### `MaxRealPerBomb = 30` について

初期設計では12に絞る想定だったが、実機計測で「半径100 × 50発でもfpsが落ちない」ことが確認されたため、**絞らない**方針に変更した。理由は `Config.Debris.MaxRealPerExplosion`(30)と `Config.Performance.MaxUnanchoredParts`(1000)がすでに全体を頭打ちにしているため。

**タブレット実機で30fpsを割った場合の対処順**:
1. `MaxRealPerBomb` を `30` → `12` に下げる
2. それでも足りなければ `Config.Performance.MaxUnanchoredParts` を `1000` → `600`

## 4. 投下ロジック(`WeaponServer.lua`)

### 4-1. 爆撃線の決め方

- プレイヤーがクリックした地点を**爆撃線の中心**とする
- 線の向きは、**プレイヤーの位置からクリック地点へ向かうベクトル**(XZ平面に射影)。「自分の向いている方向に爆撃が走っていく」形にする
- 線の全長は `LineLength`。中心から前後に `LineLength / 2`
- 3機は線に対して直角方向に `LineWidth / 2` ずつ離れて並ぶ(中央 / 左 / 右)

### 4-2. 投下

- 各機が `BombsPerPlane` 発を、線に沿って等間隔で落とす
- `Sequential = true` のとき: 合計18発を**1発ずつ `BombInterval` 秒おき**に爆発させる。順序は「線の始点から終点へ、機をまたいでジグザグ」にして、掃射している見た目にする
- `Sequential = false` のとき: 3機分を横並びで同時に落とす(6回 × 3発)
- 各爆発は `Explode(ctx)` を `maxReal = MaxRealPerBomb`、`source = "Airstrike"` で呼ぶ
- **`scoreScale` は渡さない**(連鎖ボーナスはリモート爆弾専用)

### 4-3. 戦闘機モデル

- **Toolbox は使わない。** `Part` を `PlaneParts`(5個)組み合わせた自作モデルとする(胴体1・主翼2・尾翼1・キャノピー1 程度)
- `Anchored = true` / `CanCollide = false`。物理は使わず座標を毎フレーム更新する
- 爆撃線の始点の手前から現れ、`PlaneSpeed` で線の上を通過し、終点の先で消える
- 高度は `DropHeight`(80)
- **すべての爆発が終わったあとに必ず `Destroy` すること**(ラウンドが変わっても残らないように、生成物は専用フォルダにまとめる)

## 5. 予告マーカーの矩形化(`EffectsClient.client.lua`)

- 現在の円形マーカーを、**爆撃線を示す矩形**に差し替える
- 寸法は `LineLength` × `LineWidth`。向きは 4-1 で決めた線の向き
- `Delay`(3秒)の間、赤く点滅させる
- 生成する Instance は **1個だけ**にすること(既存の教訓どおり、爆発の瞬間に Instance 生成を集中させない)

## 6. 演出の合流処理(重要・新規要件)

18発が0.15秒おきに爆発するため、**カメラシェイクと効果音がそのまま重なると酔う**。実機テストで「揺れが気になる」ことが確認されているので、必ず対処すること。

### 6-1. カメラシェイク

- シェイクの開始時刻を保持する
- 新しい爆発が届いたとき、**直近 0.25 秒以内にシェイクが開始されていれば、新しいシェイクを開始しない**
- 代わりに、現在走っているシェイクの**強度を `math.max` で更新するだけ**にする
- 結果として、絨毯爆撃中は「ずっと揺れ続ける」のではなく「一定強度で揺れて、終わったら収まる」になること

### 6-2. 効果音

- 同じ種別の効果音は、**直近 0.1 秒以内に再生されていれば新規に再生しない**
- 18個の `Sound` インスタンスが同時に存在しないようにする
- 対象は爆発音(`Explosion`)。他の音には影響させないこと

### 6-3. 適用範囲

この合流処理は**エアストライク専用にせず、爆発エフェクト全般に効かせる**。リモート爆弾の10連鎖でも同じ問題が起きるため。

## 8. `SETUP.md` の更新

「ゲームバランスの調整」の節に以下を追記する。

- `Config.Weapons.Airstrike.Cooldown`(既定20): 次に使えるまでの秒数。1ラウンド120秒なので、20なら約6回使える
- `Config.Weapons.Airstrike.LineLength` / `LineWidth`(既定120 / 20): 爆撃線の長さと編隊の幅。広げるほど1回で壊せる範囲が増える

- `Config.Weapons.Airstrike.MaxRealPerBomb`(既定30): 1発あたりに物理で飛ばす瓦礫の上限。**タブレットで重いときは最初にここを12へ下げる**
