## 1. なぜこの2つを入れるか(設計意図。実装judgment の拠り所)

### 1-1. `enemyDeploy` の目的は「装飾」ではなく「因果の教示」

`MaxDeployTrips = nil`(無制限)に変更されたため、**パトカーは警官の無限供給源**になっている。
プレイヤーがこのゲームで最初に学ばなければならないルールは:

> **警官が湧き続けるのは、あの車が原因。車を壊せば止まる。**

これを学べないプレイヤーは、湧き続ける警官を延々撃ち続けて時間切れになる。
したがってこの演出の成否は「きれいかどうか」ではなく、
**プレイヤーの視線が車に向くかどうか**で判定する。

### 1-2. 被弾フラッシュの目的は「手応えの回復」

`PoliceCar.Hits` が引き上げられた結果、**当てても4回は画面上で何も起きない**。
現状の敵エフェクトは `enemyAim` / `enemyShot` / `enemyKill` の3種で、
「当たったが生きている」に対応するものが無い(元々すべての敵が `Hits = 1` だったため)。

これは実機フィードバックで既に一度対処した問題と同じ構造である。
`Config.Threat.Damage.Invincible` を 2.0 → 0 に変更した際の理由は
「体力表示が無いゲームで無敵中の被弾を無視すると『当たっているのに減らないバグ』に見えるため」だった。
**いま敵側で同じことが起きている。**

## 2. `enemyDeploy`(降車演出)

### 2-1. サーバー側

手順5で実装した `deployFromCar` の中、警官を生成した直後に1行足す。

```lua
Effect:FireAllClients("enemyDeploy", { position = <車の位置> })
```

- `isFallback`(強制降車)でも**同じ演出を出す**。区別しない
- 送るのは位置だけ。既存のエフェクト送信の作法に合わせること

### 2-2. クライアント側(`EffectsClient`)

ディスパッチに `enemyDeploy` の分岐を追加する。

**内容: 車の位置から外向きに広がる薄いリングを1つ。**

- 平たい円柱(`Shape = Cylinder` または薄い `Part`)、`Material = Neon`、`Anchored = true`、`CanCollide = false`
- 色は警察らしい青系(`Config.Threat.EnemyTypes.PoliceCar.BodyColors.Sub` を流用してよい)
- 半径 2 → **12 程度**まで広げながら `Transparency` を 1 へ。**0.4秒**で完了 → `Destroy`
- 生成する Instance は**この1個だけ**

### 2-3. 派手にしないこと ★重要

`MaxDeployTrips = nil` かつ `DeployInterval = 10` で、パトカーは2台いる。
つまり**平均5秒に1回**この演出が出る。

したがって以下は**入れないこと**:

| 入れないもの | 理由 |
|---|---|
| カメラシェイク | 5秒ごとに画面が揺れる。既存の爆発シェイクも埋もれる |
| 大きな効果音 | 5秒ごとに鳴ると耳障りになり、ミュートされる |
| 画面全体のフラッシュ・テロップ | 建物破壊やタイム増減の演出を潰す |

音を付けたい場合は `Config.Sounds` に空文字のキーを1つ用意するに留める
(既存の `Siren` / `EnemyShot` が空文字で登録されている作法に合わせる)。
**空文字は鳴らないだけでエラーにならない。** 実際の音源選定は後回しでよい。

### 2-4. 半径 12 の根拠

警官は車の左右 4.5 stud に降りる(手順5)。リングが 12 まで広がることで、
**降りた警官がリングの内側に収まる** → 「車から出てきた」という因果が視覚的につながる。
小さすぎると車だけの演出に見え、大きすぎると爆発と紛らわしくなる。

## 3. 敵の被弾フラッシュ

### 3-1. 対象を絞る ★重要

**`Hits > 1` の敵種別にのみ適用する。** 現状はパトカーのみ(将来の戦車も該当)。

`Hits = 1` の敵(警官・将来の兵士)は1発で死ぬため、被弾フラッシュが出る状況が存在しない。
全個体に付けると、後述の `Highlight` の描画上限を無駄に消費する。

判定は `etype.Hits > 1` で行う。**種別名(`"PoliceCar"`)でのベタ書き分岐は禁止。**
Config 駆動の原則を守ること。

### 3-2. 実装方針: 生成時に作って Enabled を切り替える

**被弾のたびに Instance を作らないこと。**
`NPCManager` の `createHelpBubble` で確立済みの作法(生成時に作って `Enabled` を切り替えるだけ)を踏襲する。
これは「爆発の瞬間に Instance 生成を集中させない」という既存の教訓によるもので、
被弾は爆発と同時に起きるため、まさにこの教訓が当てはまる場面である。

**`Highlight` インスタンスを使う。**

```lua
-- spawnEnemy 内、モデル生成後(etype.Hits > 1 のときだけ)
local hl = Instance.new("Highlight")
hl.FillColor        = Color3.fromRGB(255, 255, 255)
hl.OutlineColor     = Color3.fromRGB(255, 255, 255)
hl.FillTransparency = 0.5
hl.Enabled          = false
hl.Adornee          = <モデル>
hl.Parent           = <モデル>
enemy.hitFlash = hl
```

被弾して生き残ったとき:

```lua
if enemy.hitFlash then
    enemy.hitFlash.Enabled = true
    task.delay(0.12, function()
        if enemy.hitFlash and enemy.hitFlash.Parent then
            enemy.hitFlash.Enabled = false
        end
    end)
end
```

- `Highlight` はモデルの子なので、**モデルが消えれば一緒に消える**。後片付け不要
- `task.delay` の中で `Parent` を確認しているのは、0.12秒の間に車が破壊された場合の保護

### 3-3. 発火条件

**「ダメージが入り、かつ生き残った」ときだけ。**

| 状況 | フラッシュ |
|---|---|
| ダメージが入り、残り Hits > 0 | **出す** |
| ダメージが入り、撃破された | **出さない**(既存の `enemyKill` 演出があるため) |
| `HitCooldown` 中で無効化された被弾 | **出さない**(ダメージが入っていないため) |

3つ目が重要。無効化された被弾で光らせると「当たったのに減らない」という
**まさに避けたい誤解を生む**。ダメージが実際に減った経路にだけ置くこと。

### 3-4. `Highlight` の描画上限に関する注意

Roblox の `Highlight` は同時に描画できる数に上限がある(概ね31)。
`Hits > 1` の敵に絞れば ★1 で2個、★3 で戦車2個程度なので問題にならない。

**将来、全敵に付けたくなった場合はこの上限を思い出すこと。**
その場合は `Highlight` ではなく、パーツの `Color` を直接書き換えて戻す方式に切り替える。

## 5. 受け入れ基準

### 降車演出
- [ ] パトカーが警官を降ろすたび、車の位置から青いリングが広がって消える
- [ ] 降りた警官がリングの内側に見える(「車から出てきた」と分かる)
- [ ] 強制降車(未到着)のときも同じ演出が出る
- [ ] **リングが 0.4秒程度で確実に消える**(残留しない)
- [ ] 2台が同時に降車しても演出が重ならず処理落ちしない
- [ ] 5秒に1回のペースで出ても**うるさく感じない**(感じるなら報告すること)

### 被弾フラッシュ
- [ ] パトカーにバズーカを当てると、白く一瞬光って戻る
- [ ] **撃破の1発では光らない**(`enemyKill` 演出のみ)
- [ ] 警官には Highlight が作られていない(Explorer で確認)
- [ ] 光った直後にパトカーを破壊してもエラーが出ない
- [ ] 光りっぱなしで固まらない

### 既存機能の非破壊
- [ ] 手順5の降車が従来どおり(左右のドア横に2人・強制降車の保険)
- [ ] 手順6の湧き分散が従来どおり
- [ ] 手順4の走行挙動が変わっていない
- [ ] `squadId` の全滅判定が従来どおり(パトカーを倒すまで次の波が来ない)
- [ ] 3武器すべてで従来どおり爆発・破壊・スコア加算が起きる
- [ ] 市民NPCの挙動が従来どおり
- [ ] 爆発・全壊・タイム増減の既存演出が従来どおり(新演出に埋もれていない)
- [ ] ラウンドが LOBBY → BATTLE → RESULT を1周する
- [ ] 次の LOBBY で敵が全部消える(**Highlight もモデルごと消えている**)
- [ ] `Config.Threat.Enabled = false` で敵が一切出ない
- [ ] 出力ウィンドウ(サーバー・クライアント両方)に赤いエラーが1つも出ない
