### 1-1. `squadId` の全滅判定の方式 ★最重要

編成(wave)の全滅判定が、次のどちらの実装になっているかを確認する。

| 方式 | 内容 | 手順5との相性 |
|---|---|---|
| **A案** | その `squadId` を持つ**いま生きている敵の数**を毎回数える | ✅ 途中で敵が増えても正しく動く |
| **B案** | 編成時の**予定数から撃破数を引く**カウンタを持つ | ❌ 降車で敵が増えた瞬間に破綻する |

**B案だった場合は実装に入らず、その時点で報告して指示を仰ぐこと。**
B案のまま降車を実装すると、「警官を倒しただけで次の波が来る」か「パトカーを倒しても永遠に
次の波が来ない」のどちらかになる。これは手順5の受け入れ基準そのものの破壊にあたる。

`ThreatManager.lua` は Step 3 では変更しない約束なので、**勝手に直さないこと。**

`spawnEnemy(type, position, squadId)` の第3引数が、生成された個体に確実に保持されるかを確認する。

## 3. 個体ごとの状態

パトカー1台につき以下を持たせる。

```lua
car.tripsUsed    = 0            -- これまでの降車回数
car.lastDeployAt = nil          -- 最後に降車した時刻(os.clock())。未降車なら nil
car.spawnedAt    = os.clock()   -- ★新規。湧いた時刻
car.arrived      = false        -- 目的地に到着しているか(手順4で実装済み)
```

`car.spawnedAt` は `spawnEnemy` 内で**全種別に対して**セットしてよい(害がなく、他の敵でも後で使える)。
`Body` や `Movement` による分岐を増やさないこと。

## 4. 降車の判定(共有 Heartbeat 内)

`updateRoadEnemy` の中、または移動処理の直後に置く。**到着している間ずっと評価する。**

```lua
if cfg.DeployOnArrive then
    local canDeploy = (cfg.MaxDeployTrips == nil) or (car.tripsUsed < cfg.MaxDeployTrips)
    if canDeploy then
        -- その回の降車が「解禁される時刻」
        local base = car.lastDeployAt
                     and (car.lastDeployAt + cfg.DeployInterval)
                     or  car.spawnedAt
        local waited = os.clock() - base

        if waited >= 0 and car.arrived then
            deployFromCar(car, false)          -- 通常降車
        elseif waited >= cfg.DeployFallbackTime then
            deployFromCar(car, true)           -- 強制降車(保険)
        end
    end
end
```

### この式の意図(重要・変更しないこと)

- **1回目**: `base = spawnedAt`。到着すれば即降車。到着できなくても湧いてから10秒で強制降車
- **2回目**: `base = lastDeployAt + 15`。1回目から15秒後に解禁され、到着していれば即降車。
  到着できなければ1回目から25秒後に強制降車

**なぜ保険が要るか**: 降車は「目的地まで `StopDistance`(15)以内」に入って初めて起きる。
プレイヤーが逃げ続けると目的地が更新されて `arrived` が false に戻り続けるため、
最悪の場合1人も降りない。パトカーは攻撃しないので、そうなると★1が完全に無害化し、
かつ「パトカーを倒すまで次の波が来ない」仕様のせいでそのラウンドは敵ゼロのまま終わる。

**なぜ「湧いてから10秒」ではなく「解禁されてから10秒」か**: 前者だと1回目にしか保険が効かず、
2回目は「到着できないと永久に降りない」状態が残るため。

## 5. `deployFromCar(car, isFallback)` の中身

```lua
local function deployFromCar(car, isFallback)
    local cfg = <PoliceCar の EnemyTypes 定義>
    local cf  = car.model:GetPivot()
    local right = cf.RightVector
    local look  = cf.LookVector

    for i = 1, cfg.DeployCount do
        local side = (i % 2 == 1) and 1 or -1                      -- 左右交互
        local lon  = (math.random() * 2 - 1) * cfg.DeployLongOffset -- 前後にランダム
        local pos  = cf.Position
                   + right * (side * cfg.DeploySideOffset)
                   + look  * lon
        spawnEnemy(cfg.DeployType, pos, car.squadId)   -- ★ 第3引数を必ず渡す
    end

    car.tripsUsed    = car.tripsUsed + 1
    car.lastDeployAt = os.clock()

    if isFallback then
        print(("[EnemyManager] PoliceCar 強制降車(未到着) trip=%d"):format(car.tripsUsed))
    end
end
```

### 降ろす位置について

**車の左右のドア横に降ろす。円周ランダムにはしない。**
車体は 6 × 12 stud あるため、半径6の円でランダムに降ろすとボンネットや車内から
警官が生えてくる絵になる。

- 中心から左右 4.5 stud → 車体の側面(半幅3)から 1.5 stud 離れる
- 2人なら左右1人ずつ
- 道路中心線からの最大距離は `LaneOffset`(4) + 4.5 = 8.5 stud。歩道の内側に収まる

### Y座標について

**Y の計算をここに書かないこと。** `spawnEnemy` 側が `etype.SpawnY`(PoliceOfficer = 3)で
上書きする仕様になっている(手順2で決定済み)。`cf.Position.Y`(車の 2.6)をそのまま渡してよい。

### `squadId` の引き継ぎ ★最重要

`spawnEnemy` の第3引数に `car.squadId` を必ず渡す。
渡し忘れると編成の全滅判定が壊れ、「パトカーを倒しても永遠に次の波が来ない」または
「警官を倒しただけで次の波が来る」のどちらかになる
(`THREAT_DESIGN_PROPOSAL.md` §7-1 ★9)。

### 強制降車のログ

`isFallback` のときだけ出力を1行出す。実機テストで「保険が常時発動していないか」を
確認するための計測用。毎フレーム出さないこと(降車は最大2回なので自然に2行以内に収まる)。

## 6. 車が破壊された場合

- 破壊時点で降車の評価ループから外れる(以降その車から警官は増えない)
- **すでに降ろした警官は消えない。** 独立した個体として通常どおり扱われる
- `squadId` の生存カウントからその車が1体減る

破壊処理は手順1〜4で実装済みのものをそのまま使う。降車のためだけに破壊処理を書き換えないこと。

---

## 7. `MaxDeployTrips` を使い切った車

**走り去らせない。** 引き続きプレイヤーを追尾して停車するが、もう降車しない。
倒せば `+500点 / +8秒` は入る。

(走り去らせると `squadId` の生存判定が崩れ、パトカーを倒さなくても次の波が来てしまうため。
「置物に見える」問題は手順5完了後の実機確認で改めて判断する。**この手順では実装しない。**)

## 9. 受け入れ基準(この手順で確認するもの)

### 降車の基本
- [ ] 目的地に到着すると、警官2人が**車の左右のドア横**に降りる
- [ ] 降りた警官が車体にめり込んでいない(ボンネットや車内から生えてこない)
- [ ] 降りた警官が建物にめり込んでいない
- [ ] 放置すると15秒後に追加の警官2人が降りる
- [ ] **3回目は起きない**(`MaxDeployTrips = 2` で打ち止め)
- [ ] 降車前にパトカーを破壊すると、その車からは以降誰も降りてこない
- [ ] 降ろされた警官は、あとで車を破壊しても消えない

### 保険(`DeployFallbackTime`)
- [ ] 走り回って車を到着させないようにすると、湧いてから10秒で警官が降りる
- [ ] そのとき出力に `[EnemyManager] PoliceCar 強制降車(未到着) trip=1` が出る
- [ ] 普通にプレイしている限り、このログが**ほとんど出ない**(常時出るなら報告すること)

### 編成・波の制御 ★この手順の本題
- [ ] **降ろされた警官を全員倒しても、パトカーが生きている限り次の波が来ない**
- [ ] パトカーも倒すと `RespawnDelay`(20秒)後に次の波が来る
- [ ] `MaxDeployTrips` を使い切ったパトカーも、倒すまで次の波を止め続ける

### 既存機能の非破壊
- [ ] 手順4の走行挙動が変わっていない(道路の上だけを走る・角で曲がる・追尾する)
- [ ] 3武器すべてで従来どおり爆発・破壊・スコア加算が起きる
- [ ] 市民NPCの挙動が従来どおり
- [ ] ラウンドが LOBBY → BATTLE → RESULT を1周する
- [ ] 次の LOBBY で敵が全部消え、★が `☆` に戻る
- [ ] `Config.Threat.Enabled = false` で敵が一切出ない
- [ ] 出力ウィンドウ(サーバー・クライアント両方)に赤いエラーが1つも出ない
